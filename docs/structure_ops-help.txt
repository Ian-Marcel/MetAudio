Usage: metaudio --structure-operation=[OPTIONS]

STRUCTURE OPERATIONS:
  track_positioner
      Reads the track number from each audio file's metadata and prepends it
      to the filename.

  sort_album_type
      Prepends a type prefix to each album's folder name based on its track
      count: S/Single, EP/Extended Play, or FL/Full Length.

  artist_base_structure
      Reads the AlbumArtist tag from the first track of each album folder and
      reorganizes albums into an Artist/Album structure under the origin
      directory. Skips any album whose first track has no AlbumArtist tag set.

  help
      Show this help message.

EXAMPLES:
  metaudio --structure-operation=artist_base_structure 
  metaudio -s=track_positioner,sort_album_type
