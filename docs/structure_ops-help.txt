Usage: metaudio -s=[OPTIONS]

STRUCTURE OPERATIONS:
  track_positioner
      Reads the track number from each audio file's metadata and prepends it
      to the filename.

  sort_album_type
      Prepends a type prefix to each album's folder name based on its track
      count: S/Single, EP/Extended Play, or FL/Full Length.

  help
      Show this help message.

EXAMPLES:
  metaudio -s=track_positioner 
  metaudio -s=sort_album_type 
  metaudio -s=track_positioner,sort_album_type
