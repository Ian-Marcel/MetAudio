Usage: metaudio -m=[OPTIONS]

METADATA OPERATIONS:
  multiple_artists
      Splits a single ARTIST tag containing multiple artists into a primary
      ARTIST entry and separate entries for contributing artists, while also
      setting the first artist as ALBUMARTIST. Intended for Navidrome
      compatibility. FLAC ONLY.

  set_album_name
      Sets the ALBUM tag on files where it is missing, using the existing
      TITLE tag value as the source. Has no effect on files that already
      have an ALBUM tag set.

  trim_artwork
      Trims embedded artwork or cover art with a disproportionate aspect ratio
      down to 1:1, which is the standard ratio.

  set_album_artist
      Surveys the AlbumArtist tag across all tracks in each album folder. If
      the tag is missing or set in a minority of tracks, falls back to the
      Artist tag instead — splitting comma or feat.-delimited values before
      counting. For FLAC files where multiple_artists has already run, the
      existing ARTISTS tags are read directly without splitting. The value
      appearing most frequently across all tracks is then written as
      AlbumArtist on every track in the album.

  help
      Show this help message.

EXAMPLES:
  metaudio -m=multiple_artists 
  metaudio -m=multiple_artists,trim_artwork 
  metaudio -m=set_album_name,trim_artwork
